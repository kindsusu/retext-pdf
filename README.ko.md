PDF의 텍스트를 직접 고치고, 민감한 글자를 실제로 제거하는 Windows용 로컬 편집기입니다. Markdown 편집도 함께 됩니다. 모든 처리는 PC 안에서 이뤄지며 문서는 PC 밖으로 나가지 않습니다.

## 다운로드

**권장: [Microsoft Store에서 받기](https://apps.microsoft.com/detail/9MXQD6ZHX6HH)** — Microsoft가 서명한 패키지라 SmartScreen 경고 없이 설치되고, 새 버전이 나오면 Store가 자동으로 업데이트합니다.

설치 파일을 직접 받으려면 **[Releases](https://github.com/kindsusu/retext-pdf/releases/latest)**에서 받습니다.

| 파일 | 이럴 때 |
|---|---|
| `Retext-PDF-<버전>-setup.exe` | 일반 설치(사용자별, 관리자 권한 불필요). PDF "연결 프로그램" 목록과 시작 메뉴에 등록됩니다. |
| `Retext-PDF-<버전>-portable.exe` | 설치 없이 폴더나 USB에서 바로 실행합니다. |

요구 사항: Windows 10·11(x64), 디스크 약 400MB. 계정이나 인터넷 연결이 필요 없습니다.

**처음 실행할 때 SmartScreen(Releases 설치 파일만).** Releases의 exe는 코드 서명이 없어 "Windows의 PC 보호" 창이 뜰 수 있습니다. 이 저장소의 Releases에서 받은 파일인지 확인한 뒤 **추가 정보 → 실행**을 누르세요. 또는 받은 파일을 우클릭 → **속성** → **차단 해제**에 체크 → 확인을 누르면 경고 없이 열립니다. 경고를 피하려고 Microsoft Defender를 끄지 마세요.

## 5.1의 새 기능

> **보안 수정 — 사각형 가리기로 가린 파일을 다시 확인하세요.** 4.0.1부터 5.0.0까지 사각형 **가리기** 도구는 덮개 상자만 그렸고, 그 아래 글자와 그림은 파일에 그대로 남아 복사·추출할 수 있었습니다. 5.1.0부터 사각형 가리기는 상자 아래 내용을 실제로 지웁니다 — 글자는 지우고, 상자 아래 그림 픽셀은 칠하고, 겹치는 주석은 지운 뒤 덮습니다. 이전 버전에서 사각형 가리기를 쓴 파일이 있으면 5.1에서 열어 같은 자리를 다시 가리세요. 줄 편집 창의 **선택 글자 가리기**·**줄 전체 가리기**는 처음부터 글자를 실제로 지웠으므로 해당하지 않습니다.

- **리본.** 도구줄이 **홈 · 주석 · 쪽 · 문서 · 보안** 탭으로 나뉜 리본이 되었습니다. 모든 기능은 여전히 그림과 이름이 있는 버튼으로 보입니다. 왼쪽 패널은 **파일 | 쪽 | 주석 | 목차** 탭입니다. 쪽 목록 끌어 옮기기를 새로 만들어 여러 쪽을 한꺼번에 옮기고, 놓일 자리에 선이 보이고, 가장자리에서 목록이 저절로 넘어갑니다.
- **주석.** 형광펜·밑줄·취소선·메모·사각형·원·선(화살표)·펜. 색·불투명도·굵기를 고릅니다. 주석 목록(거르기, 눌러서 그 자리로)과 **모두 고정**(주석을 쪽 내용으로 굳히기). 모양 정보(appearance stream)를 함께 써서 다른 PDF 뷰어에서도 보입니다.
- **워터마크**(글자·그림, 불투명도, 회전, 설정 저장)와 **머리말·꼬리말**(`{page}` `{pages}` `{date}` `{file}` `{title}` 표시).
- **목차(책갈피) 고치기** — `제목<TAB>쪽번호` 글로 한꺼번에 고치기(들여쓰기로 단계)도 됩니다. **문서 정보**(제목·작성자·주제·키워드) 고치기. **이미지 PDF로 저장**(쪽을 그림으로 바꿔 숨은 글자·주석·메타데이터가 모두 빠짐).
- **보안 탭의 개인정보 도구.** 개인정보 찾아 가리기(이메일·전화번호·주민등록번호·사업자등록번호·카드번호·직접 쓴 정규식, 검사 숫자가 있는 번호는 검사), 같은 영역 여러 쪽 가리기, 숨은 데이터 제거(문서 정보·XMP 메타데이터·첨부 파일·자바스크립트).
- 같은 작업 중에 만든 주석을 지우면 저장한 파일에 글자가 따로 남던 문제를 고쳤습니다.
- **줄 묶기 개선.** 공백으로 띄운 양식 칸은 따로 두고, 가짜·이중 공백이 생기지 않으며, 위첨자·아래첨자는 줄 안에 남습니다. 회전한 글자, 줄 끝 하이픈, 양쪽 맞춤·자간을 벌린 줄, 괘선 없는 표와 2단 사이 여백을 구분하고, 읽는 순서는 단을 따릅니다. 굵게·기울임·색이 섞인 줄도 한 상자이며, 고쳐도 조각마다 모양이 유지됩니다.
- **문단 고치기.** 줄을 두 번 클릭(또는 Ctrl+클릭)하면 문단 전체를 고치고, 글은 문단 폭에 맞춰 다시 흐릅니다.

## 주요 기능

- 원본 임베드 폰트를 유지한 채 PDF 텍스트 객체를 직접 편집 (없는 글리프는 맑은 고딕 서브셋으로 대체)
- 선택한 문자를 PDF에서 제거한 뒤 재추출로 확인하는 가리기(마스킹); 검색 결과를 우클릭해 "줄 전체 가리기"도 가능; 사각형 가리기는 상자 아래 글자·그림 픽셀·주석을 지움
- 개인정보 도구: 개인정보 찾아 가리기(이메일·전화·주민등록번호·사업자등록번호·카드번호·정규식), 같은 영역 여러 쪽 가리기, 숨은 데이터 제거(문서 정보·XMP·첨부 파일·자바스크립트)
- 주석(형광펜·밑줄·취소선·메모·사각형·원·선/화살표·펜)과 주석 목록·모두 고정 — 다른 뷰어에서도 보임
- 워터마크, 머리말·꼬리말, 목차(책갈피) 고치기, 문서 정보 고치기, 이미지 PDF로 저장
- 문서 전체 텍스트 검색(Ctrl+F) — 이전/다음 이동, 건수 표시, 대소문자 구분, 강조 표시
- 쪽 도구: 쪽 정리(추출/삭제), 90도 회전, 순서 변경, 복제, 빈 쪽·다른 PDF 끼워 넣기, 쪽 번호, N쪽씩 분할, 병합, PNG/JPEG로 내보내기, 다운샘플링으로 용량 줄이기(파일 여러 개를 열지 않고 한 번에 줄이는 것도 가능)
- 내용 넣기: 글 상자, 도장 보관함의 도장·서명, JPEG/PNG 그림
- 인쇄(Ctrl+P), 암호 걸린 PDF 열기, AES-256 암호를 건 사본 저장
- 상태줄(현재쪽/전체쪽, 쪽 번호 입력, 확대 비율 목록 — 쪽 전체 보기·폭 맞춤·50~400%)과 사이드바 파일 | 쪽 | 주석 | 목차 탭(열어 둔 파일, 쪽 목록, 주석, 목차)
- 문서가 없을 때 빠른 도구(병합·여러 파일 용량 줄이기·이미지로 내보내기)가 있는 빈 상태와 전체 창 드래그 앤 드롭 오버레이
- Windows "연결 프로그램" 등록으로 브라우저·메일에서 PDF 바로 열기 (임시 파일은 배너와 "다른 이름으로 저장" 안내)
- 실행 취소/다시 실행, 여러 줄·문단 편집(두 번 클릭 또는 Ctrl+클릭, 문단 폭에 맞춰 다시 흐름), 폭 맞춤, 이동 — 정렬을 유지한 편집도 Ctrl+Z 한 번에 되돌아갑니다
- 안전한 편집: 줄을 고치면 적용 → 저장 → 다시 열기 → 확인을 거친 뒤에만 반영하고, 실패하면 원래대로 되돌립니다
- 오래 걸리는 문서 도구(용량 줄이기·내보내기·분할·병합·페이지 정리)는 진행 창과 [취소] 버튼을 제공하며, 취소하면 문서를 원래 상태로 되돌리거나 그때까지 저장된 파일 수를 알려줍니다
- 페이지 삭제·용량 줄이기·회전·순서 변경 뒤에는 실행 취소 토스트가 뜨고, 알림은 서로 덮어쓰지 않고 쌓입니다
- Markdown 편집과 안전한 실시간 미리보기

## 소스에서 실행

```bash
git clone https://github.com/kindsusu/retext-pdf.git
cd retext-pdf
npm install
npm start
```

터미널 없이 같은 소스를 실행하려면 `run-retext-pdf.bat`을 더블클릭합니다. 브라우저 전용 모드는 `npm run serve` 후 <http://localhost:4747>에서 열리며, 이 모드에서는 파일 대화상자와 PNG 삽입을 쓸 수 없습니다(Electron 전용).

## PDF 편집

![구조](assets/architecture.svg)

한 줄을 클릭해 내용을 바꾸고 Enter로 확정합니다. 두 번 클릭(또는 Ctrl+클릭)하면 문단 전체를 고칩니다. 엑셀·한글·Chromium이 내보낸 PDF는 한 줄을 글꼴 경계나 글자마다 쪼개 저장하는데, 기준선이 같고 붙어 있는 조각을 한 상자로 묶어 줄 단위로 고칠 수 있게 합니다(표의 옆 칸·공백으로 띄운 양식 칸·단은 간격과 세로 괘선, 단 사이 여백으로 구분해 묶지 않습니다). 굵게·기울임·색이 섞인 줄도 한 상자이며, 고쳐도 조각마다 모양이 유지됩니다. 가능한 한 원본 임베드 폰트를 유지하며, 원본에 없는 글자는 맑은 고딕으로 대체됩니다. 이미지 위의 투명 검색 글자이거나 이미 폰트를 지정한 텍스트 상자는 **폰트 맞추기** 창이 열립니다 — 설치된 폰트를 고르거나 TTF를 가져와 미리보기 후 적용하며, 실행 취소를 지원합니다. 그림으로 그려진 글자처럼 원래 글꼴을 다시 쓸 수 없으면 창이 그렇게 알려 주고, 비슷한 글꼴을 직접 골라 미리 보며 맞춥니다. 일반 TTF만 지원하며 OTF나 가변 폰트는 지원하지 않습니다.

![가리기 절차](assets/redaction.svg)

텍스트 가리기는 선택한 문자를 PDF 객체에서 제거하고 가리는 사각형을 추가한 뒤, 페이지 텍스트를 재추출해 제거를 확인합니다. 사각형 **가리기** 도구는 5.1.0부터 상자 아래 글자를 지우고, 그림 픽셀을 칠하고, 겹치는 주석을 지운 뒤 덮습니다. 양식 개체(Form XObject) 안 내용은 덮기만 할 수 있으며 그럴 때는 앱이 알려 줍니다. 줄 단위 가리기는 스캔 이미지에 그려진 글자를 지울 수 없으니, 그런 곳은 사각형 가리기로 그림 픽셀을 칠하세요.

## 개인정보와 안전

- 문서는 PC 밖으로 나가지 않습니다. 계정·클라우드·AI 연동이 없고, 내장 서버는 `127.0.0.1`에서만 동작하며 다른 사이트에서 온 요청은 거부합니다(Host·Origin 검사).
- Markdown 안의 링크는 기본 브라우저로 열고, 원격 이미지는 자동으로 불러오지 않습니다.
- 가리기는 글자를 파일에서 실제로 지운 뒤 페이지 텍스트를 다시 추출해 확인합니다. 스캔 이미지는 사각형 가리기로 상자 아래 픽셀을 칠합니다.
- **보안** 탭: 개인정보를 찾아 한꺼번에 가리기, 같은 영역 여러 쪽 가리기, 숨은 데이터 제거(문서 정보·XMP 메타데이터·첨부 파일·자바스크립트). **이미지 PDF**는 글자 층이 전혀 없는 사본을 저장합니다.

## PDF 도구

리본의 **홈**·**주석**·**쪽**·**문서**·**보안** 탭은 아래 기능을 제공합니다(이미지로 내보내기·분할·이미지 PDF·암호는 새 파일을 만들 뿐 열린 문서는 그대로라 실행 취소 대상이 아니고, 나머지는 모두 실행 취소 가능).

- **글 상자**(`T`) — 쪽을 눌러 입력. 글꼴·크기·색은 상황줄에서 고릅니다
- **도장**(`S`) — 도장 보관함의 PNG/JPEG 도장·서명을 찍기, 드래그로 이동, 손잡이로 크기 조절
- **그림** — JPEG/PNG를 삽입, 드래그로 이동, 손잡이로 크기 조절
- **가리기**(`W`) — 끌어서 감싼 영역 아래 글자·그림 픽셀·주석을 지우고 덮기
- **주석** 탭 — 형광펜·밑줄·취소선·메모·사각형·원·선(화살표)·펜, 주석 목록, 모두 고정
- **왼쪽 / 오른쪽** — 현재 쪽(쪽 목록에서 여러 쪽을 골랐으면 그 쪽들)을 90도 회전
- **빈 쪽** / **끼워 넣기** — 현재 쪽 뒤에 빈 쪽 또는 다른 PDF의 쪽들을 넣기
- **쪽 번호** — 모든 쪽에 쪽 번호 넣기(형식·위치·크기·여백·시작 번호·첫 쪽 건너뛰기·색). 다시 넣으면 이전 번호를 바꿉니다
- **머리말·꼬리말** — 여섯 자리에 글 넣기, `{page}` `{pages}` `{date}` `{file}` `{title}` 표시
- **워터마크** — 글자 또는 그림, 불투명도·회전·위치, 설정 저장
- **목차** — 왼쪽 패널에서 책갈피를 보고 고치기, `제목<TAB>쪽번호` 글로 고치기
- **쪽 정리…** — 축소본 체크박스 또는 `1,3-5` 범위로 쪽을 추출/삭제
- **병합** — 여러 PDF를 원하는 순서로 병합
- **이미지로** — 쪽을 96~300dpi PNG/JPEG로 폴더에 저장
- **용량 줄이기** — 기준 dpi 이상 이미지를 다운샘플링하고 JPEG로 재압축, 목표 용량 지정 가능(투명 이미지는 건너뜀). 문서를 열지 않은 상태에서는 PDF 여러 개를 한 번에 줄여 원본 옆에 "…-축소.pdf"로 저장합니다
- **분할** — N쪽씩 잘라 고른 폴더에 새 PDF 여러 개로 저장
- **문서 정보** — 제목·작성자·주제·키워드 고치기
- **이미지 PDF** — 쪽을 그림으로 바꾼 사본 저장(글자·주석·메타데이터 없음)
- **암호** — 열기 암호와 인쇄·복사·수정 제한(선택)을 건 AES-256 사본을 저장. 열어 둔 문서는 바뀌지 않습니다
- **개인정보 찾기**, **여러 쪽 가리기**, **숨은 데이터 제거**

사이드바 **쪽** 탭에서는 Ctrl·Shift+클릭으로 여러 쪽을 고르고, 끌어서 순서를 바꾸고(놓일 자리에 선이 보이고 가장자리에서 목록이 저절로 넘어감), Delete로 지우고, PDF 파일을 끌어다 놓아 그 자리에 끼워 넣습니다. 우클릭 메뉴에는 왼쪽/오른쪽으로 돌리기, 복제, 앞에/뒤에 빈 쪽, PDF 끼워 넣기, 따로 저장…(고른 쪽만 새 PDF로), 지우기가 있습니다.

회전한 쪽에서도 글줄·가림 상자·검색 강조·드래그 이동이 화면과 어긋나지 않습니다 — 화면 표시는 PDF의 회전 전 좌표계와 회전 후 화면 배치를 서로 변환해 맞춥니다.

## 자주 묻는 질문

**SmartScreen 경고를 없앨 수 있나요?** [Microsoft Store판](https://apps.microsoft.com/detail/9MXQD6ZHX6HH)은 Microsoft가 서명해 경고가 없습니다. Releases의 exe는 서명이 없어 위의 "추가 정보 → 실행" 또는 "차단 해제"를 써야 합니다.

**고친 글자가 맑은 고딕으로 바뀌었어요.** PDF에는 보통 이미 쓰인 글자 모양만 들어 있습니다. 원래 글꼴에 없는 새 글자는 맑은 고딕으로 그립니다. **폰트 맞추기**로 더 비슷한 설치 글꼴이나 TTF를 지정할 수 있습니다.

**수정이 이유와 함께 거부됐어요.** 어떤 글꼴로도 그릴 수 없는 수식 기호·이모지가 든 줄, 그리고 입력한 글자와 다른 글자가 저장되는 일부 PDF 글꼴은 틀린 글을 저장하지 않도록 수정을 막습니다.

**암호가 걸린 PDF도 열 수 있나요?** 네. 암호를 물어 엽니다. 인쇄·편집만 제한한 PDF는 바로 열립니다. 첫 저장은 "다른 이름으로 저장"으로 하며 저장한 사본에는 암호가 없으니, 다시 잠그려면 **암호**를 쓰세요.

## 한계

- Windows 10 이상을 주 대상으로 하며 Windows 11에서 검증했습니다.
- 스캔 이미지 안의 글자는 직접 편집하지 않습니다.
- 복잡한 CJK 합자·세로쓰기·특수 폰트는 폴백이 필요할 수 있습니다.
- 회전한 쪽에 찍은 도장은 쪽과 함께 돌아갑니다. 도장 보관함의 도장은 이름을 바꿀 수 없습니다.
- 원래 글꼴에 없는 글자는 맑은 고딕으로 그립니다.
- 고친 문단이 길어지면 늘어난 줄은 문단 아래에 붙지만 그 아래 내용을 밀어내지는 않습니다. 겹치면 앱이 알려 줍니다.
- 암호 걸기는 파일을 새로 쓰므로 기존 전자서명은 무효가 됩니다.
- 상업·업무용 사용은 라이선스를 확인해야 합니다.
