## 다운로드

**권장: [Microsoft Store에서 받기](https://apps.microsoft.com/detail/9MXQD6ZHX6HH)** — Microsoft가 서명한 패키지라 SmartScreen 경고 없이 설치되고, 새 버전이 나오면 Store가 자동으로 업데이트합니다.

설치 파일을 직접 받으려면 **[Releases](https://github.com/kindsusu/retext-pdf/releases/latest)**에서 받습니다.

| 파일 | 이럴 때 |
|---|---|
| `Retext-PDF-<버전>-setup.exe` | 일반 설치(사용자별, 관리자 권한 불필요). PDF·Markdown·텍스트·그림 파일의 "연결 프로그램" 목록(기본 앱은 그대로)과 시작 메뉴에 등록됩니다. |
| `Retext-PDF-<버전>-portable.exe` | 설치 없이 폴더나 USB에서 바로 실행합니다. |

요구 사항: Windows 10·11(x64), 디스크 약 400MB. 계정이나 인터넷 연결이 필요 없습니다.

**처음 실행할 때 SmartScreen(Releases 설치 파일만).** Releases의 exe는 코드 서명이 없어 "Windows의 PC 보호" 창이 뜰 수 있습니다. 이 저장소의 Releases에서 받은 파일인지 확인한 뒤 **추가 정보 → 실행**을 누르세요. 또는 받은 파일을 우클릭 → **속성** → **차단 해제**에 체크 → 확인을 누르면 경고 없이 열립니다. 경고를 피하려고 Microsoft Defender를 끄지 마세요.

## 6.1의 새 기능

- **텍스트 파일 열기.** `.txt`는 미리보기 없는 편집 칸으로 엽니다. 인코딩(UTF-8, BOM 있는 UTF-8·UTF-16, 한국어 CP949)을 알아보고, 저장할 때 같은 인코딩과 줄바꿈으로 씁니다. CP949로 쓸 수 없는 글자가 있으면 UTF-8로 저장할지 묻습니다. `.markdown`은 `.md`처럼 엽니다.
- **그림을 PDF로 열기.** PNG·JPG·WebP·GIF(첫 장면)·BMP를 한 쪽짜리 새 PDF로 엽니다. 여러 장을 고르면 한 PDF로 합칠 수 있습니다. 그다음 가리기·글자 인식·서명·PDF로 저장을 그대로 씁니다.
- **"연결 프로그램" 등록 확대.** 설치판과 Store판이 `.md`·`.markdown`·`.txt`와 그림 파일의 Windows "연결 프로그램" 목록에 Retext PDF를 올립니다. 기본 앱은 바꾸지 않습니다.
- **더 작은 패키지**(테스트 파일을 앱에서 뺌)와 더 안정적인 테스트.
- 한계: 텍스트·Markdown 편집 칸에는 찾아 바꾸기와 맞춤법 검사가 없습니다. 움직이는 GIF는 첫 장면만 엽니다.

## 6.0의 새 기능

> **5.1.0 보안 안내는 지금도 유효합니다:** 4.0.1~5.0.0의 사각형 **가리기** 도구는 덮개 상자만 그렸습니다. 그 버전에서 사각형 가리기를 쓴 파일은 다시 열어 같은 자리를 가려 주세요([자세히](https://github.com/kindsusu/retext-pdf/releases/tag/v5.1.0)).

- **쪽 위에서 바로 고치기.** 줄을 누르면 그 자리에서 쪽의 글꼴·크기·색 그대로 고칩니다. 치는 대로 글이 다시 흐르고, 손잡이로 상자 폭을 바꾸거나 옮깁니다. 문단이 길어지면 같은 단의 아래 내용을 밀어 내리고, 쪽에 자리가 모자라면 글자 줄이기·겹치기·취소 중에서 고르게 합니다. `Ctrl+Enter` 적용, `Esc` 취소.
- **속성 창과 글자 꾸밈.** 오른쪽 속성 창에서 고치는 줄의 글꼴·크기·색·정렬·줄 간격·자간을 봅니다. 글자를 골라 굵게·기울임·밑줄·취소선·위첨자·아래첨자를 주거나 글꼴·크기·색을 바꿉니다 — 속성 창이나 고른 글자 위의 작은 꾸밈 막대에서. 설치된 굵은·기울인 글꼴이 있으면 그것을 씁니다.
- **찾아 바꾸기**(`Ctrl+H`) — 조각마다 굵게·기울임·색을 지키며 바꾸고, 모두 바꾸기도 실행 취소 한 번에 되돌아갑니다.
- **맞춤법 검사(인터넷 없이)** — Hunspell과 한국어·영어 사전. 고치는 동안 틀린 낱말에 물결 밑줄, 고칠 말 제안, 내 사전, 글자 모양을 지키며 고치는 문서 전체 검사.
- **글자 인식(OCR, 인터넷 없이)** — 한국어·영어 스캔 쪽에 보이지 않는 검색용 글자 층이나 보이는 편집용 글자를 넣고, 끌어 감싼 곳만 읽을 수도 있습니다. 인식한 글자로 찾기·복사·개인정보 찾기·내보내기·가리기를 할 수 있습니다.
- **글자 선택 도구**(`V`) — 끌기, 두 번 클릭 낱말, 세 번 클릭 줄, `Ctrl+A`, `Ctrl+C`(줄바꿈 유지, 줄 끝 하이픈 잇기). 오른쪽 클릭으로 고른 글자에 형광펜·가리기.
- **변환과 비교.** Word(`.docx`)·한글(`.hwpx`)·Markdown·텍스트로 내보내기(제목·목록·표·굵게·색 유지). 두 PDF를 나란히 비교하고 넣은·지운·바뀐 글을 목록으로 봅니다.
- **양식 채우기**(AcroForm) — 글·체크 상자·라디오·콤보·목록 칸, 꼭 채울 칸 확인, 초기화, 데이터 내보내기·가져오기(JSON·FDF·XFDF), 양식 고정.
- **일괄 처리** — 여러 파일에 13가지 작업: 워터마크, 머리말·꼬리말, 쪽 번호, 베이츠 번호, 숨은 데이터 제거, 개인정보 가리기, 암호, 이미지 PDF, 용량 줄이기, Markdown, Word, 한글, 글자 인식.
- **쪽·문서 도구 추가.** 쪽 자르기(끌기·여백·내용에 맞춰)와 쪽 크기 바꾸기, 링크(웹 주소·쪽)와 첨부 파일, 영역 스냅샷(클립보드·PNG), 여러 파일에 이어지는 베이츠 번호.
- **작업 화면.** 문서 탭(탭마다 보기와 적용 전 수정을 따로 기억), 명령 검색(`Ctrl+Q`, 초성으로도), 어두운 테마·시스템 따라가기, 최근 파일이 있는 시작 화면, 한 쪽·두 쪽 보기와 읽기 모드, 손 도구(`Space`+끌기).
- **더 안전한 결과.** 원래 글꼴에 없는 글자는 같은 집안의 설치 글꼴을 먼저 쓰고, 저장 전에 바뀐 글꼴을 알려 줍니다. 고치지 않은 부분은 자간(커닝)을 그대로 둡니다. 회전한 줄은 줄마다 덮개 하나. 전자서명된 PDF를 알아보고 사본으로 저장합니다. 실제 가리기가 양식 개체(Form XObject) 안의 글자·그림 픽셀·선까지 지우고, 일부만 가린 투명 그림도 투명함을 지킵니다.

## 주요 기능

- PDF 텍스트 객체를 쪽 위에서 바로 고치기 — 줄·문단 단위, 치는 대로 다시 흐름, 폭 손잡이, 길어진 문단은 아래 내용을 밀어 내림
- 고른 글자 꾸미기(굵게·기울임·밑줄·취소선·위첨자·아래첨자·글꼴·크기·색) — 속성 창이나 작은 꾸밈 막대에서. 원본 임베드 폰트를 유지하고, 없는 글자는 같은 집안 설치 글꼴, 그다음 맑은 고딕
- 글자 모양을 지키는 찾아 바꾸기, 문서 전체 텍스트 검색(Ctrl+F) — 이전/다음 이동, 건수 표시, 대소문자 구분, 강조 표시
- 선택한 문자를 PDF에서 제거한 뒤 재추출로 확인하는 가리기(마스킹). 사각형 가리기는 상자 아래 글자·그림 픽셀·주석을 지우며, 양식 개체 안까지 지움
- 개인정보 도구: 개인정보 찾아 가리기(이메일·전화·주민등록번호·사업자등록번호·카드번호·정규식), 같은 영역 여러 쪽 가리기, 숨은 데이터 제거(문서 정보·XMP·첨부 파일·자바스크립트)
- 인터넷 없이 하는 글자 인식(OCR, 한국어·영어)과 맞춤법 검사(한국어·영어) — 어디로도 보내지 않음
- 글자 선택·복사, 주석(형광펜·밑줄·취소선·메모·사각형·원·선/화살표·펜)과 주석 목록·모두 고정, 링크, 첨부 파일
- 워터마크, 머리말·꼬리말, 쪽 번호, 베이츠 번호, 목차(책갈피) 고치기, 문서 정보 고치기, 이미지 PDF로 저장
- 쪽 도구: 쪽 정리(추출/삭제), 회전, 순서 변경, 복제, 빈 쪽·다른 PDF 끼워 넣기, 자르기, 쪽 크기, 분할, 병합, PNG/JPEG로 내보내기, 용량 줄이기(여러 파일 한 번에도)
- 변환과 비교: Markdown·텍스트, Word(DOCX), 한글(HWPX)로 내보내기, 두 PDF 나란히 비교, 여러 파일 일괄 처리
- 양식 채우기(AcroForm)와 데이터 내보내기·가져오기, 양식 고정
- 내용 넣기: 글 상자, 도장 보관함의 도장·서명, JPEG/PNG 그림, 영역 스냅샷
- 인쇄(Ctrl+P), 암호 걸린 PDF 열기, AES-256 암호를 건 사본 저장, 전자서명된 PDF는 알아보고 사본으로 저장
- 문서 탭, 명령 검색(Ctrl+Q), 어두운 테마, 최근 파일이 있는 시작 화면, 한 쪽·두 쪽 보기와 읽기 모드, 손 도구, 쪽 이동·확대 비율이 있는 상태줄
- Windows "연결 프로그램" 등록으로 브라우저·메일에서 PDF 바로 열기 (임시 파일은 배너와 "다른 이름으로 저장" 안내)
- 거의 모든 편집의 실행 취소/다시 실행. 안전한 편집 — 고치면 적용 → 저장 → 다시 열기 → 확인을 거친 뒤에만 반영하고, 실패하면 원래대로 되돌립니다
- 오래 걸리는 도구의 진행 창과 [취소] 버튼, 쪽을 바꾼 뒤의 실행 취소 토스트, 서로 덮어쓰지 않고 쌓이는 알림
- Markdown 편집과 안전한 실시간 미리보기, 인코딩(UTF-8·UTF-16·CP949)과 줄바꿈을 지키는 텍스트(`.txt`) 편집
- 그림(PNG·JPG·WebP·GIF·BMP)을 한 쪽짜리 PDF로 열기, 여러 그림을 한 PDF로 합치기

## 소스에서 실행

```bash
git clone https://github.com/kindsusu/retext-pdf.git
cd retext-pdf
npm install
npm start
```

터미널 없이 같은 소스를 실행하려면 `run-retext-pdf.bat`을 더블클릭합니다. 브라우저 전용 모드는 `npm run serve` 후 <http://localhost:4747>에서 열리며, 이 모드에서는 파일 대화상자와 PNG 삽입을 쓸 수 없습니다(Electron 전용).

## PDF 편집

![구조](assets/architecture.svg)

줄을 누르면 쪽 위에서 바로 고칩니다. `Ctrl+Enter`(또는 바깥 누르기)로 적용, `Esc`로 취소, `Enter`는 줄바꿈입니다. 두 번 클릭(또는 Ctrl+클릭)하면 문단 전체를 고치고, 글은 문단 폭에 맞춰 다시 흐르며, 길어지면 같은 단의 아래 내용을 밀어 내립니다. 오른쪽 속성 창에서 글꼴·크기·색·정렬·줄 간격·자간을 바꾸고, 글자를 고르면 고른 글자에만 줍니다. 창이 좁을 때(그리고 투명 글자·묶은 상자·회전 글자)는 떠 있는 편집 창이 열립니다. 엑셀·한글·Chromium이 내보낸 PDF는 한 줄을 글꼴 경계나 글자마다 쪼개 저장하는데, 기준선이 같고 붙어 있는 조각을 한 상자로 묶어 줄 단위로 고칠 수 있게 합니다(표의 옆 칸·공백으로 띄운 양식 칸·단은 간격과 세로 괘선, 단 사이 여백으로 구분해 묶지 않습니다). 굵게·기울임·색이 섞인 줄도 한 상자이며, 고쳐도 조각마다 모양이 유지됩니다. 가능한 한 원본 임베드 폰트를 유지하며, 원본에 없는 글자는 같은 집안의 설치 글꼴, 그다음 맑은 고딕으로 그리고, 저장 전에 바뀐 글꼴을 알려 줍니다. **폰트 맞추기** 창에서는 설치된 폰트를 고르거나 TTF를 가져와 미리보기 후 적용하며, 실행 취소를 지원합니다. 그림으로 그려진 글자처럼 원래 글꼴을 다시 쓸 수 없으면 창이 그렇게 알려 주고, 비슷한 글꼴을 직접 골라 미리 보며 맞춥니다. 일반 TTF만 지원하며 OTF나 가변 폰트는 지원하지 않습니다.

![가리기 절차](assets/redaction.svg)

텍스트 가리기는 선택한 문자를 PDF 객체에서 제거하고 가리는 사각형을 추가한 뒤, 페이지 텍스트를 재추출해 제거를 확인합니다. 사각형 **가리기** 도구는 상자 아래 글자를 지우고, 그림 픽셀을 칠하고, 겹치는 주석을 지운 뒤 덮습니다. 6.0부터는 양식 개체(Form XObject, 여러 번 쓰는 쪽 내용) 안에서도 지우고, 투명 그림은 투명함을 지킵니다. 상자를 가로지르는 그러데이션(셰이딩)처럼 덮기만 할 수 있는 것은 앱이 알려 줍니다. 줄 단위 가리기는 스캔 이미지에 그려진 글자를 지울 수 없으니, 그런 곳은 사각형 가리기로 그림 픽셀을 칠하거나 먼저 글자 인식을 하세요.

## 개인정보와 안전

- 문서는 PC 밖으로 나가지 않습니다. 계정·클라우드·AI 연동이 없고, 내장 서버는 `127.0.0.1`에서만 동작하며 다른 사이트에서 온 요청은 거부합니다(Host·Origin 검사).
- 글자 인식과 맞춤법 검사는 앱에 든 언어 데이터로 PC 안에서 하며, 작업 스레드는 네트워크 접근을 막습니다.
- Markdown 안의 링크는 기본 브라우저로 열고, 원격 이미지는 자동으로 불러오지 않습니다.
- 가리기는 글자를 파일에서 실제로 지운 뒤 페이지 텍스트를 다시 추출해 확인합니다. 스캔 이미지는 사각형 가리기로 상자 아래 픽셀을 칠합니다.
- **보안** 탭: 개인정보를 찾아 한꺼번에 가리기, 같은 영역 여러 쪽 가리기, 숨은 데이터 제거(문서 정보·XMP 메타데이터·첨부 파일·자바스크립트). **이미지 PDF**는 글자 층이 전혀 없는 사본을 저장합니다.

## PDF 도구

리본 탭에는 아래 기능이 있습니다. 새 파일을 만드는 도구(이미지로 내보내기·분할·이미지 PDF·암호·Markdown/Word/한글로 내보내기·일괄 처리)는 열린 문서를 바꾸지 않아 실행 취소 대상이 아니고, 나머지는 모두 실행 취소할 수 있습니다.

- **홈** — 열기·저장·다른 이름·인쇄·실행 취소/다시 실행. **글자 고치기**(`E`), **글자 선택**(`V`), **글 상자**(`T`), **도장**(`S`), **그림**, **가리기**(`W`), **스냅샷**(영역을 그림으로). **찾기**(`Ctrl+F`), **바꾸기**(`Ctrl+H`), 도움말
- **주석** — 형광펜(`H`)·밑줄(`U`)·취소선·메모(`N`)·사각형·원·선(화살표)·펜(`P`), 주석 목록, 모두 고정, 링크, 링크 목록
- **쪽** — 왼쪽/오른쪽 돌리기, 빈 쪽, 끼워 넣기, 쪽 정리…, 쪽 번호, 머리말·꼬리말(`{page}` `{pages}` `{date}` `{file}` `{title}`), 워터마크, 베이츠 번호, 자르기(끌어 감싸기), 여백 자르기…(여백 숫자·내용에 맞춰), 쪽 크기…, 목차
- **문서** — 병합, 분할, 이미지로(96~300dpi PNG/JPEG), 용량 줄이기(문서를 열지 않으면 여러 파일을 한 번에 줄여 "…-축소.pdf"로 저장), 문서 정보, 이미지 PDF, 첨부 파일, 글자 인식…, 영역 인식, 양식(필드 강조·양식 초기화·데이터 내보내기/가져오기·양식 고정), 맞춤법, Markdown, Word로, 한글(HWPX)로, 비교, 일괄 처리…
- **보안** — 암호(열기 암호와 인쇄·복사·수정 제한을 건 AES-256 사본), 개인정보 찾기, 여러 쪽 가리기, 숨은 데이터 제거

사이드바는 **파일 | 쪽 | 주석 | 목차 | 첨부** 탭입니다. **쪽** 탭에서는 Ctrl·Shift+클릭으로 여러 쪽을 고르고, 끌어서 순서를 바꾸고(놓일 자리에 선이 보이고 가장자리에서 목록이 저절로 넘어감), Delete로 지우고, PDF 파일을 끌어다 놓아 그 자리에 끼워 넣습니다. 우클릭 메뉴에는 왼쪽/오른쪽으로 돌리기, 복제, 앞에/뒤에 빈 쪽, PDF 끼워 넣기, 따로 저장…(고른 쪽만 새 PDF로), 지우기가 있습니다.

회전한 쪽에서도 글줄·가림 상자·검색 강조·드래그 이동이 화면과 어긋나지 않습니다 — 화면 표시는 PDF의 회전 전 좌표계와 회전 후 화면 배치를 서로 변환해 맞춥니다.

## 자주 묻는 질문

**SmartScreen 경고를 없앨 수 있나요?** [Microsoft Store판](https://apps.microsoft.com/detail/9MXQD6ZHX6HH)은 Microsoft가 서명해 경고가 없습니다. Releases의 exe는 서명이 없어 위의 "추가 정보 → 실행" 또는 "차단 해제"를 써야 합니다.

**고친 글자가 맑은 고딕으로 바뀌었어요.** PDF에는 보통 이미 쓰인 글자 모양만 들어 있습니다. 원래 글꼴에 없는 새 글자는 맑은 고딕으로 그립니다. **폰트 맞추기**로 더 비슷한 설치 글꼴이나 TTF를 지정할 수 있습니다.

**수정이 이유와 함께 거부됐어요.** 어떤 글꼴로도 그릴 수 없는 수식 기호·이모지가 든 줄, 그리고 입력한 글자와 다른 글자가 저장되는 일부 PDF 글꼴은 틀린 글을 저장하지 않도록 수정을 막습니다.

**글자 인식이나 맞춤법 검사가 문서를 어디로 보내나요?** 아니요. 둘 다 앱에 든 언어 데이터로 PC 안에서 하며, 작업 스레드는 네트워크 접근을 막습니다.

**맞춤법 검사가 맞는 낱말을 틀렸다고 해요.** 오른쪽 클릭해 내 사전에 넣거나 무시하세요. 낱말 단위 검사라 띄어쓰기는 보지 않으며, 신조어·고유명사 일부는 사전에 없습니다.

**전자서명된 PDF는 왜 "다른 이름으로 저장"해야 하나요?** 고치면 서명한 내용이 바뀌어 서명이 무효가 됩니다. 첫 수정 전에 알려 주고, 결과는 사본으로 저장해 서명된 원본을 지킵니다.

**어떤 파일을 열 수 있나요?** PDF, Markdown(`.md`·`.markdown`), 텍스트(`.txt`), 그림(PNG·JPG·WebP·GIF·BMP)입니다. 그림은 새 PDF로 열리고 "다른 이름으로 저장"으로 저장합니다. 텍스트 파일은 저장할 때 원래 인코딩(UTF-8·UTF-16·CP949)과 줄바꿈을 지킵니다. 설치한 뒤 파일을 우클릭 → **연결 프로그램** → Retext PDF로 열 수 있으며, 기본 앱은 바뀌지 않습니다.

**암호가 걸린 PDF도 열 수 있나요?** 네. 암호를 물어 엽니다. 인쇄·편집만 제한한 PDF는 바로 열립니다. 첫 저장은 "다른 이름으로 저장"으로 하며 저장한 사본에는 암호가 없으니, 다시 잠그려면 **암호**를 쓰세요.

## 한계

- Windows 10 이상을 주 대상으로 하며 Windows 11에서 검증했습니다.
- 스캔 이미지 안의 글자는 글자 인식(OCR)을 해야 고칠 수 있습니다. 목차의 점선(……)과 세로쓰기는 인식이 약하니 결과를 확인하세요.
- 맞춤법 검사는 낱말 단위라 띄어쓰기는 보지 않고, 신조어·고유명사 일부를 틀렸다고 표시합니다(내 사전에 넣으면 됩니다).
- Word(DOCX)·한글(HWPX) 내보내기는 표의 병합 칸을 만들지 않고, HWPX는 목록을 일반 글로 씁니다. 배치는 PDF와 비슷하지만 똑같지는 않습니다.
- 양식: XFA만 있는 양식은 지원하지 않습니다(앱이 알려 줌). 한글 값이 든 목록 상자는 다른 뷰어에서 다르게 보일 수 있습니다.
- 가리기: 가림 상자를 가로지르는 그러데이션(셰이딩)은 지우지 못하고 덮기만 합니다(앱이 알려 줌).
- 복잡한 CJK 합자·세로쓰기·특수 폰트는 폴백이 필요할 수 있습니다. 원래 글꼴에 없는 글자는 같은 집안 설치 글꼴, 그다음 맑은 고딕으로 그립니다.
- 텍스트·Markdown 편집 칸에는 찾아 바꾸기와 맞춤법 검사가 없습니다(PDF에서만 됩니다). 움직이는 GIF는 첫 장면만 엽니다.
- 회전한 쪽에 찍은 도장은 쪽과 함께 돌아갑니다. 도장 보관함의 도장은 이름을 바꿀 수 없습니다.
- 암호 걸기와 전자서명된 PDF 고치기는 파일을 새로 쓰므로 기존 전자서명은 무효가 됩니다(서명된 원본은 사본으로 저장).
- Releases의 설치 파일은 코드 서명이 없습니다. SmartScreen 경고 없이 쓰려면 Microsoft Store판을 받으세요.
- 상업·업무용 사용은 라이선스를 확인해야 합니다.
